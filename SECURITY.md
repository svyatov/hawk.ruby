# Security policy

## Report a vulnerability

Email [leonid@svyatov.com](mailto:leonid@svyatov.com) to report a suspected vulnerability privately. Do not disclose it in a public issue.

Include the affected gem version, Ruby version, integration, reproduction steps, and potential impact. Remove integration tokens, personal data, and other secrets from attachments.

Leonid Svyatov will send an initial response within seven calendar days. That response will acknowledge the report and identify the next investigation step.

Coordinate public disclosure with the maintainer after a fix or mitigation is available.
