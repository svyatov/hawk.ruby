# Hawk Ruby catcher implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a typed Ruby error catcher with optional Rails and job integrations, sending Hawk's native event format.

**Architecture:** One gem contains a framework-independent client, execution scopes, event construction, and bounded HTTP delivery. Separately loaded adapters share capture boundaries and duplicate tracking. Events are filtered, detached, and serialized before queueing.

**Tech Stack:** CRuby 3.3/3.4/4.0, standard libraries, RBS, Steep, RuboCop, Minitest, SimpleCov, crap4ruby, and bundler-audit.

**Spec:** [Approved design](../specs/2026-10-29-hawk-ruby-design.md)

## Global constraints

- C1: One package, `hawk-ruby` version `0.1.0`, namespace `Hawk`, MIT license for original implementation code.
- C2: CRuby 3.3, 3.4, and 4.0; Rails 7.2, 8.0, and 8.1, on valid Ruby combinations.
- C3: Rack 2 and 3; Sidekiq 7 and 8; Resque 2; Delayed Job 4; Solid Queue through Active Job.
- C4: Only standard-library runtime dependencies; Rails, job frameworks, and quality tools remain optional or development dependencies.
- C5: Check every shipped Ruby file with Steep, ship complete signatures, and require zero untyped calls.
- C6: Require 100% line and branch coverage across merged suites and CRAP scores at most 10 from fresh coverage.
- C7: No publication, production credentials, source copying, application-object mutation, or changes to job arguments or retries.
- C8: Preserve original errors, return values, response handling, and exit status when instrumentation fails.
- C9: Use Conventional Commits, branch names of `type/kebab-description`, and no attribution footers.
- C10: For every `lib/**/*.rb` addition, add its RBS signature and include it in type, coverage, CRAP, and artifact checks.

## Review focus

- R1: Streamed Rack bodies can fail after middleware returns; capture once and preserve iteration and close behavior in Task 7.
- R2: Forked children can inherit locked mutexes; recreate synchronization before acquiring inherited locks in Task 5.
- R3: Reinitialization can duplicate Rails hooks; registration stays idempotent and callbacks resolve the active client in Tasks 6-10.
- R4: Persisted job metadata can be malformed or from another application version; validate it without changing execution in Tasks 9-12.
- R5: An asynchronous worker can observe later scope changes; queue immutable serialized snapshots and test mutation in Tasks 4-5.

## Shared contracts

RBS notation defines types below. `json` is a recursive union of JSON primitives, arrays, and string-keyed objects.
Use `top` for raw boundary inputs, then narrow them by checked runtime branches. Do not replace boundary types with `untyped`.

| Interface | Exact contract |
| --- | --- |
| `Hawk.init` | `() { (Configuration) -> void } -> Client`; replaces and closes the default client |
| `Hawk::Client.new` | `(Configuration, delivery: _Delivery) -> void`; explicit delivery supports behavioral fixtures |
| `Hawk::Client.build` | `(Configuration) -> Client`; builds normal transport and delivery, including independent project clients |
| `capture_exception` | `(Exception, ?context: Hash[String | Symbol, top], ?user: Hash[String | Symbol, top]?, ?level: Symbol) -> String?` |
| `capture_message` | `(String, ?context: Hash[String | Symbol, top], ?user: Hash[String | Symbol, top]?, ?level: Symbol) -> String?` |
| `capture` | `[A] () { () -> A } -> A`; report escaping eligible errors and re-raise the same object |
| `with_scope` | `[A] () { (Scope) -> A } -> A`; inherit a detached snapshot and restore the previous scope |
| `set_context`, `set_user` | `(Hash[String | Symbol, top]) -> void`; `(Hash[String | Symbol, top]?) -> void` |
| `add_breadcrumb` | `(Hash[String | Symbol, top]) -> void` |
| `flush`, `close` | `(?timeout: Float) -> bool`; default deadline is 5.0 seconds |
| `_Delivery#enqueue` | `(String, String) -> bool`; event identifier and encoded envelope; false means rejected before delivery |
| `_Delivery#flush`, `#close` | `(timeout: Float) -> bool`; drained work can include failed delivery attempts |
| `Boundary.run` | `[A] (Client, kind: Symbol, metadata: Hash[String, json], ?inherit: bool) { () -> A } -> A` |
| `Client#report` | `(Exception, mechanism: String, ?context: Hash[String, json], ?level: Symbol, ?handled: bool) -> String?`; internal automatic report |
| `JobContext.dump` | `(Client) -> Hash[String, json]?`; only explicit user/context, filtered and bounded |
| `JobContext.load` | `(top) -> Hash[String, json]`; malformed or unsupported metadata becomes an empty object |
| `Event.new` | Configuration, local ID, optional exception/message, normalized context/user/breadcrumbs/addons, and severity; keyword inputs |

The module delegates capture, scope, user, context, breadcrumb, and lifecycle methods to its default client.
Independent clients have independent configuration, scope storage, delivery, and duplicate tracking.

Configuration defaults: `token = ENV['HAWK_TOKEN']`, `environment = ENV['RAILS_ENV'] || ENV['RACK_ENV'] || 'development'`, `enabled_environments = nil`.
Use `release = ENV['HAWK_RELEASE'] || ENV['REVISION']`; `detect_release = false` enables optional bounded Git detection at initialization.
Use `sample_rate = 1.0`, `delivery_mode = :async`, `queue_capacity = 100`, `source_roots = [Dir.pwd]`, and `send_source = true`.
Use `connect_timeout = 1.0`, `read_timeout = 2.0`, `write_timeout = 2.0`, and `flush_timeout = 5.0` seconds.
Default limit cooldown is 60 seconds; clamp `Retry-After` cooldowns to 300 seconds using a monotonic deadline.
Automatic integration switches default to enabled when explicitly loaded or activated by Rails; logging-to-error conversion defaults to disabled.
Manual breadcrumbs are enabled. Rails notifications activate with Rails; automatic Logger and HTTP breadcrumbs require explicit configuration.
Use `propagate_job_context = true`, `before_send = nil`, `before_breadcrumb = nil`, and `diagnostic_callback = nil`.
Use empty `context`, `ignored_exceptions`, and `filter_parameters`; default `user` is nil. Match ignored exception names against ancestor names without resolving constants.
`include_request_body`, `include_job_arguments`, `include_headers`, and `include_cookies` default to false.
Opted-in data still passes recursive filtering, Rails filters, hook validation, and size limits.

Use runtime configuration validation for finite sampling between 0 and 1, positive capacities, finite nonnegative deadlines, and callable hooks.
Only loopback IP literals permit custom HTTP endpoints. Reject endpoint user information, fragments, and token-bearing redirects.
Malformed nonempty tokens raise `Hawk::ConfigurationError`; missing or empty tokens disable reporting.
